Guide d’installation

Skills vidéo Cursor + HyperFrames

Pour créer des vidéos promo, explainers, motion graphics et sous-titres avec l’IA

1. Ce qu’il faut installer (une seule fois)

  • Cursor — https://cursor.com (éditeur avec agent IA)
  • Node.js 22+ — https://nodejs.org (LTS ou Current ≥ 22)
  • FFmpeg — https://ffmpeg.org/download.html (Windows : winget install ffmpeg)
  • Git (optionnel) — pour cloner le dépôt du projet
Vérification rapide (PowerShell ou Terminal) : 
node -v
npm -v
ffmpeg -version
npx hyperframes doctor
La commande doctor télécharge Chrome headless si besoin (première utilisation).

2. Qu’est-ce qu’un « skill » ?

Un skill est un fichier SKILL.md qui apprend à l’agent Cursor un workflow précis (ex. créer une vidéo explainer, ajouter des sous-titres, etc.).

Structure minimale :

nom-du-skill/
  └── SKILL.md

3. Où installer les skills

EmplacementChemin WindowsPortée
Projet (recommandé) MON-PROJET\.agents\skills\nom-du-skill\ Uniquement ce projet, partageable via Git
Personnel C:\Users\VOTRE_NOM\.cursor\skills\nom-du-skill\ Tous vos projets Cursor
Global agents (optionnel) C:\Users\VOTRE_NOM\.agents\skills\nom-du-skill\ Copie globale sur la machine
Ne pas utiliser le dossier .cursor\skills-cursor\ — réservé à Cursor en interne.

4. Méthode A — Cloner le projet (le plus simple)

  1. Cloner ou copier le dossier du projet (ex. cours-de-soutien).
  2. Ouvrir ce dossier dans Cursor : Fichier → Ouvrir le dossier.
  3. Les skills sont déjà dans .agents\skills\ — rien à télécharger de plus.
  4. Dans le chat Agent, demander par exemple :
    « Crée une vidéo promo 30s avec le skill hyperframes »

5. Méthode B — Copier les skills à la main

  1. Copier tout le dossier .agents\skills\ depuis le projet source.
  2. Coller dans le projet de votre ami : SON-PROJET\.agents\skills\
  3. Ou coller chaque skill dans C:\Users\...\ .cursor\skills\ pour usage global.
  4. Redémarrer Cursor ou rouvrir le workspace.

6. Méthode C — Installation auto via HyperFrames

En créant un nouveau projet vidéo, HyperFrames peut installer les skills :

mkdir C:\Videos\mon-projet
cd C:\Videos\mon-projet
npx hyperframes init ma-video --non-interactive
npx hyperframes doctor

8. Workflow pour créer une vidéo

# 1. Créer le projet
npx hyperframes init ma-promo --example product-promo

# 2. Entrer dans le dossier
cd ma-promo

# 3. Contrôler et prévisualiser
npx hyperframes lint
npx hyperframes preview

# 4. Exporter le MP4
npx hyperframes render

Dans Cursor Agent, vous pouvez aussi écrire :

« Utilise le skill faceless-explainer pour créer une vidéo de 60 secondes sur [sujet]. Style premium bleu/cyan. »

9. Choisir le bon skill (aide-mémoire)

10. Dépannage

ProblèmeSolution
L’agent n’utilise pas le skillNommer explicitement : « Utilise le skill hyperframes »
npx hyperframes introuvableVérifier Node 22+ ; relancer le terminal
Render échouenpx hyperframes doctor puis réinstaller FFmpeg
Skills invisiblesVérifier le chemin .agents\skills\ ou .cursor\skills\

11. Checklist pour votre ami

  • Cursor installé
  • Node.js 22+ installé
  • FFmpeg installé
  • Projet ouvert dans Cursor
  • Dossier .agents\skills\ présent (ou skills copiés)
  • npx hyperframes doctor OK
  • Premier test : npx hyperframes init test-video --non-interactive
